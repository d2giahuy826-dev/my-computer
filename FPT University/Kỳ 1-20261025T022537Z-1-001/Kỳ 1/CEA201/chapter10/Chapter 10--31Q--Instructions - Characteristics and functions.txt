Chapter 10: Instructions - Characteristics and functions
---

1. What is an instruction in a computer system?
a. A command given to the computer to perform a specific task
b. A file that contains data to be processed by the computer
c. A device used to input data into the computer
d. A program used to control the computer's operation
Answer: a

2. What is the instruction set architecture (ISA)?
a. The set of instructions that a computer can understand and execute
b. The hardware components that make up a computer
c. The software programs that run on a computer
d. The input/output devices of a computer
Answer: a

3. What is the purpose of the instruction register (IR) in a computer system?
a. To hold the current instruction being executed
b. To store data that is being processed by the computer
c. To act as the primary memory for the computer
d. To store the next instruction to be executed
Answer: a

4. Which of the following is not a characteristic of instructions?
a. Opcode
b. Operand
c. Address
d. Flow
Answer: d

5. What is an opcode?
a. The operation code that specifies the operation to be performed
b. The data that is being operated on

Answer: a

a. The data that is being operated on

Answer: a

7. What is an address?

d. The condition for executing the instruction
Answer: a

8. What is the purpose of the program counter (PC) in a computer system?

c. To store data that is being processed by the computer
