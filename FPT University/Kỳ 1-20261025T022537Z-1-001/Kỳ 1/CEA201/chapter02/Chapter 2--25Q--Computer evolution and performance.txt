Chapter 2: Computer evolution and performance
--

1. Which of the following is not a characteristic of a first-generation computer?
a) They used vacuum tubes
b) They were large and expensive
c) They were slow and had limited memory
d) They were portable
Answer: d) They were portable

2. Which of the following is not an example of a second-generation computer technology?
a) Magnetic core memory
b) Transistors
c) Vacuum tubes
d) Magnetic tape
Answer: c) Vacuum tubes

3. Which of the following is not an advantage of integrated circuits (ICs)?
a) They are smaller and more reliable than discrete circuits
b) They are less expensive to produce than discrete circuits
c) They allow for more complex circuitry
d) They generate less heat than discrete circuits
Answer: d) They generate less heat than discrete circuits

4. Which of the following is not a factor that affects computer performance?
a) Processor speed
b) Memory capacity
c) Storage capacity
d) Number of peripherals
Answer: d) Number of peripherals

5. Which of the following is not a type of non-volatile memory?
a) Magnetic disk
b) Flash memory
c) ROM
d) EEPROM
Answer: a) Magnetic disk

6. Which of the following is not a type of volatile memory?
a) RAM
b) ROM
c) Cache memory
d) Virtual memory
Answer: b) ROM

7. What is the purpose of a cache memory?
a) To store frequently accessed data for faster access
b) To store permanent data even when the computer is turned off
c) To store temporary data while the computer is running
d) To store backup copies of important files
Answer: a) To store frequently accessed data for faster access

8. Which of the following is not a type of magnetic storage media?
a) Hard disk
b) Floppy disk
c) Magnetic tape
d) Optical disk
Answer: d) Optical disk

9. Which of the following is not a factor that affects processor performance?
a) Clock speed
b) Cache size
c) Number of cores
d) Amount of RAM
Answer: d) Amount of RAM

10. What is the primary function of the operating system?
a) To provide a graphical user interface
b) To manage system resources
c) To run applications
d) To connect to the internet
Answer: b) To manage system resources

11. Which of the following is not a type of computer software?
a) System software
b) Utility software
c) Application software
d) Keyboard software
Answer: d) Keyboard software

12. What is the purpose of a device driver?
a) To allow the computer to communicate with peripherals
b) To control the clock speed of the processor
c) To manage the computer's memory
d) To perform system maintenance tasks
Answer: a) To allow the computer to communicate with peripherals

13. Which of the following is not a type of high-level programming language?
a) Java
b) C++
c) Assembly language
d) Python
Answer: c) Assembly language

14. What is the purpose of a compiler?
a) To translate high-level programming code into machine code
b) To translate machine code into high-level programming code
c) To manage system resources
d) To connect to the internet
Answer: a) To translate high-level programming code into machine code
