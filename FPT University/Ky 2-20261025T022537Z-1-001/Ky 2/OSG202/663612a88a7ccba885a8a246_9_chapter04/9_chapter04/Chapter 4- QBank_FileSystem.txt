Chapter 4: File systems

1. Which of the following is a common file system used in Windows?
a) NTFS
b) Ext4
c) HFS+
d) ZFS
Answer: a) NTFS

a) FAT16
b) FAT32

Answer: c) HDFS

a) FAT32

8. Which file system was designed specifically for use with CD-ROMs?

d) Ext4

a) NTFS

a) NTFS
b) Ext4

a) NTFS

18. What is a file system?

B) A collection of files and directories

A) NTFS

A) NTFS
B) FAT32

Answer: D

23. What is a partition?
A) A collection of files and directories
B) A logical section of a hard drive
C) A hardware component of a computer
D) A network protocol
Answer: B

24. What is the purpose of a journaling file system?
A) To optimize file access speed
B) To reduce the risk of data loss in the event of a power outage or system crash
C) To allow for remote access to files
D) To compress file data
Answer: B

25. Which file system is used by macOS operating systems?
A) NTFS
B) FAT32
C) HFS+
D) ext4
Answer: C

26. What is a cluster?
A) A group of computers connected by a network
B) A group of files stored together on a hard drive
C) A group of processes running on a computer
D) A group of network protocols
Answer: B

27. What is fragmentation?
A) The process of compressing files
B) The process of moving files to a different location on a hard drive
C) The process of breaking files into smaller pieces and storing them in non-contiguous locations on a hard drive
D) The process of encrypting files
Answer: C

28. What is a file allocation table (FAT)?
A) A table that maps the physical location of files on a hard drive
B) A table that lists all the files on a hard drive
C) A table that lists all the directories on a hard drive
D) A table that maps the logical location of files on a hard drive
Answer: A

29. What is a directory?
A) A group of files stored together on a hard drive
B) A logical section of a hard drive
C) A hardware component of a computer
D) A collection of network protocols
Answer: A

30. Which file system is commonly used in embedded systems?

Answer: C

31. What is a mount point?

B) The logical location of a hard drive
C) The physical location of a file on a hard drive
D) The logical location of a file on a hard drive

32. What is a symbolic link?

B) A link between two files with different names
